
# Tic Tac Toe (XO) Game

A Java-based Tic Tac Toe game built with the MVVM architecture, supporting single-player and multiplayer modes.

## Features
- Single-player mode
- Multiplayer over LAN
- GUI using Swing
- MVVM pattern
